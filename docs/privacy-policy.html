隐私政策

最后更新：2026 年 11 月 8 日

本政策说明「星光·Starlight」网站（下称"本站"）如何处理与访问者有关的信息。 简单说：本站是一个纯静态的介绍页面，不设账号、不收集个人信息、不做访问统计。

1. 本站收集哪些信息

不收集。具体来说，本站：

  • 没有注册、登录或任何表单，不需要你提交姓名、邮箱、手机号；
  • 不设置 Cookie，不使用 localStorage 或类似机制保存你的信息；
  • 不接入任何第三方统计、广告或用户画像脚本；
  • 页面内的星空动画完全在浏览器本地绘制，不上传任何数据。

2. 托管服务与访问日志

本站托管在 GitHub Pages。与所有网站一样，托管方会在其服务器上记录访问日志 （通常包含 IP 地址、请求时间、浏览器类型与来源页面），用于安全防护和故障排查。 这部分数据由 GitHub 处理，适用 GitHub 隐私声明，本站无法读取也无法删除。

3. 下载与外部链接

Android 安装包（APK）通过 GitHub Releases 提供，PC 版同样跳转 GitHub 下载。 点击下载按钮后你会离开本站，之后的访问与下载行为适用 GitHub 的服务条款与隐私政策。 本站不记录下载次数，也无法知道谁下载了什么。

页面中另有若干外部链接（如赞助页、国际版站点、北京服务器地址），它们各自有独立的隐私政策， 本站不对这些站点的做法负责。

4. QQ 群

本站提供社区 QQ 群的二维码与群号。扫码或搜索加群时，你使用的是腾讯 QQ 的服务， 相关数据处理适用腾讯的隐私政策。进群后你主动发送的群昵称、消息等内容， 群内成员（包括我们）可以看到；除此之外我们不会索取你的任何个人信息。

5. 字体文件

本站使用的 Lexend 字体已随站点一起托管，从本站域名直接加载。 页面不会向 Google Fonts 或其他字体服务发起请求，因此不会因此向第三方暴露你的 IP 地址。

6. 关于星光 App 本身

本政策仅适用于本站（网站）。星光 App 在设备上的数据处理方式， 以 App 内的说明为准。需要说明的是：App 使用你现有的 Among Us 账号登录， 不会另建账号，也不会看到或保存你的密码。

7. 未成年人

本站不面向 13 岁以下儿童，也不会主动收集任何人的个人信息。若你认为我们意外持有了未成年人的信息， 请通过下方方式联系我们，我们会尽快处理。

8. 政策变更

如果本站将来新增功能（例如评论区或访问统计），本政策会同步更新，并在此页顶部的"最后更新"日期体现。 重大变更会在首页公告中提示。

9. 联系我们

对本政策有疑问，欢迎加入 QQ 群 451561679 与我们联系。
